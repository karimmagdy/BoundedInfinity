\begin{abstract}

Recursive multi-agent LLM systems---in which agents spawn sub-agents
that spawn further sub-agents---accumulate unbounded sub-agent state
(task descriptions, reasoning traces, tool outputs), exhausting
context windows and host memory and crashing long-running runs.
Frameworks such as LangGraph, AutoGen, CrewAI, and MetaGPT all store
every agent state in unbounded Python data structures and offer no
principled memory limit.  We present \emph{Bounded Infinity Cache}
(BIC), a memory-bounded cache for recursive agent state that combines
three ingredients: (i)~a deterministic Cantor-pairing address that
maps tree positions to fixed-array slots, (ii)~an optional Hilbert
space-filling curve for locality-preserving eviction, and
(iii)~hierarchical, LLM-eligible summarization that compresses
evicted child states into their parents.  We prove $\Oh(M)$ cache
memory for capacity $M$ and $\Oh(\log_k N)$ retrieval depth for
branching factor $k$.  On a 50-agent recursive research-decomposition
swarm using Gemini-2.0-flash (5 seeds, 3 cache sizes), BIC achieves
$4.1\times$ higher semantic reconstruction quality than LRU eviction
at 20\% retention ($0.303 \pm 0.016$ vs.\ $0.074 \pm 0.009$) with
100\% query success, while LRU loses access to 81\% of agents.  A
synthetic stress test with 3{,}280 agents at 1.9\% retention
($9.4\times$ improvement over LRU) confirms the bound at scale.  BIC
is a concrete memory-management primitive for the next generation of
recursive LLM agent systems.

\end{abstract}
